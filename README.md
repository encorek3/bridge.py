# bridge.py - 橋樑檢測管理系統 (台灣標準版)

本專案依據台灣交通部「公路橋梁檢測及補強規範」與「橋梁定期檢測評等準則」開發，將橋梁檢測的 DERU 評等邏輯程式化，並結合 OpenCV 實作無人機空拍影像的初篩機制，輔助檢測人員管理與追蹤橋梁缺陷。

## 功能特性

* **DERU 評定與自動排程**
  * 完整對應 D(劣化程度)、E(劣化範圍)、R(影響度)、U(急迫性) 0~4 級距評分。
  * 內建排程引擎：自動依據最高 U 值判定修繕時限。若發現高急迫性缺陷 (U ≥ 3)，系統會自動將下次定檢週期縮短至 12 個月內。
* **結構化檢測紀錄**
  * 支援四大構件分類（橋面、上部結構、下部結構、涵管）。
  * 可記錄傳統目視 (Visual/Manual)、無人機 (AI Drone) 及非破壞性檢測 (NDT) 需求。
* **無人機影像自動初篩**
  * 使用 OpenCV (Canny 邊緣偵測與形態學) 標註影像中的可疑裂縫與剝落。
  * 支援批次處理資料夾內的空拍影像，並依「偵測數量 × 信心值」計算風險權重，自動排序產出「優先複核清單」，降低檢測人員看圖的時間成本。
